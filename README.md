# conductor2

Conductor doctrine plus the packaged handshake artifact surface required for
current parity work.

- Canonical doctrine: `skill/SKILL.md`
- Shared lifecycle artifacts: `conductor/index.md`, `conductor/workflow.md`, `conductor/tracks.md`
- Install with `install.sh` from outside this source tree; the packaged `conductor/` surface includes `index.md`, `workflow.md`, and `tracks.md`

- `gemini-extension.json` is Gemini host metadata, not doctrine
